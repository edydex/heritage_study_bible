# Heritage 1.1.36-preview.1

Android versionCode 39. Install over the existing Heritage app.

- English-only built-in songs no longer show a Russian subtitle in the song list. The two bundled Russian hymns retain their Russian titles.
- If a church supplies a Russian title for another version of the same song, the combined listing can show that title. Existing title aliases still group church and built-in versions together.
- Lyrics, saved songs, notes, church connections and calendar behavior are unchanged.
