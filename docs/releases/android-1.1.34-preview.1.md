This preview refreshes Community songs from their church server and adds the church calendar.

- Open Songs or pull down from the top to refresh. A successful response replaces the church’s saved song list, removing titles no longer Published. Admin accounts see the same published songbook as everyone else.
- Refresh stops after about five seconds if the server does not respond. A small message appears and saved songs remain available. A failed request does not remove local songs or downloads.
- Opening a published song saves its English and Russian words on this device. Previously opened songs remain readable during a server outage; songs never downloaded still need a connection once.
- The first connected launch refreshes older song catalogs even if they were recently checked. Personal notes, highlights, progress and Bible downloads are preserved.
- Community → Calendar shows Events by default; enable Recurring for regular services. The server applies church and event visibility settings. Recurring services keep their local time across daylight saving changes.

This package uses version code 37 and the same development signer as previous Heritage releases. Install it over the old app; do not uninstall first. It is available through the in-app update checker.

Church administration in this update also gains Solo/Choir/Communal song tags, alphabetical ordering within tags, calendar date-click creation, saved calendar defaults, and a sermon slide workspace whose whole presentation can be added to a service.

This remains a development preview. Automated and browser checks cover refresh retention, calendar privacy and recurrence, and saved bilingual sermon slides. Test the pull-down gesture and the calendar on your actual phone after installation.
