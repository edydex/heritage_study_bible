This Community preview brings the current Heritage integration to Android:

- Community Home links to church resources, live video and translation.
- Published sermons appear beside their Bible passages and in church archives.
- Member song links use the church sign-in, with English/Russian text and explicit offline saving.
- Personal notes and reading progress can sync through a Community server; church membership is separate.

The APK is signed with the same development certificate as v1.1.32 and uses a higher version code. Install it as an update to keep existing reading data; do not uninstall the previous app first.

This remains a development preview. Automated Android acceptance covers the packaged Community screens, native encrypted storage and activity restart. Real phone sign-in, sharing, live translation, audio and venue testing remain pending. No translation API key or data-sharing opt-in is bundled with the app.
