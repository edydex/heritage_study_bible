Bible audio highlighting now moves straight to the next verse when the previous
verse ends. Normal pauses between verses no longer leave the reading marker
blank. If the next verse has no accepted timestamp, it can still be shown as
the next reading position; the next verified audio interval brings following
back into alignment.

This changes the reading display, not the stored timings. Tapping a verse still
seeks only when its exact timestamp is verified. During a run of several
untimed verses, the marker stays on the first following verse until a verified
interval resumes. It skips empty text entries and leaves narrator introductions
unmarked.

Includes the internal Maximus reading text and audiobook following added in
1.1.46, plus the earlier contextual translations in original-word results.
