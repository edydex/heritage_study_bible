Parallel word lookup now shows how the original word is translated in each
occurrence. Results include the full BSB verse, the checked translated phrase
and highlighted source/translated wording. Contextual differences such as
“servant,” “slaves,” and “in slavery” are retained.

Checked BSB/Greek links now cover 6,596 New Testament verses across all 27 books,
so English word taps and holds are no longer limited to Romans. The links come
from Berean's published tables and are used only when both complete verse texts
agree with the installed editions. Different readings and unavailable word
mappings are clearly labeled; no translation is guessed. BSB context is also
shown for Hebrew/Aramaic word-form results without claiming word alignment.

Mappings load only for the books currently displayed and can be retried without
losing the source results. The Android package includes all mappings for offline
use. Turning off link colors/patterns retains source-lemma lookup. Existing
notes, highlights, downloads and reading/audio positions are retained.
