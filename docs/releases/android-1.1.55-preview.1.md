# Heritage 1.1.55 preview 1

- Added Expand beside the commentary work details to open a full-screen reading view. Restore, Back, or Escape returns to the commentary pane while retaining the reading position.
- Volume buttons now scroll the open commentary in both layouts. Repeated down presses at its end no longer advance the Bible or reading plan behind it.
- Commentary scrolling uses its own text size, viewport and reading marker. Opening another view cancels any previous scrolling animation.

LSV source formatting is preserved. The current source has paragraph markers only at chapter starts; adding paragraph divisions within chapters would require an editorial layout.

This update includes the existing 1.1.54 reader, audio, offline storage and Community features. Automated Android acceptance covers packaged reading, storage, sync and audio behavior. Physical-device review of the new commentary controls remains to be completed.
