# Published sermons in Heritage

Open **Community Home → Sermons and notes** for the selected church, or **Resources → Sermons** for all installed sources. Search titles, speakers, series or Scripture. Open a card to read the church's reviewed manuscript, notes or transcript and access its published recordings. When more than one text language is supplied, use **Text language**. Heritage displays the published text without generating a translation.

In the Bible reader, select a verse. The commentary panel shows **On this passage** for sermons whose main reading covers it. **Appears in N sermons** lists messages that mention the verse. Opening and closing a sermon keeps the selected Bible passage.

Only enabled sources that advertise the public sermon publication format participate. Previously saved church manifests refresh automatically to discover the new capability. No member token is sent to a public publication request. Detail bytes must match the reviewed catalog revision and checksum; unsafe links, redirects and unexpected private fields are rejected. A failed sermon fetch does not stop the Bible reader, and a stalled request times out after 15 seconds.

Publications remain a deliberate church-manager decision. Draft manuscripts, private preparation notes and live AI translation are not automatically published. A church with no approved publications shows an empty archive. A withdrawn or unavailable publication is reported explicitly.

Catalog and detail caching in this reader is currently in memory. Previously verified material can survive a temporary server interruption during the current view; a fresh offline app launch is not a downloaded-sermon library. Audio starts only when requested and uses the published recording host.
