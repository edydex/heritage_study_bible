# BSB Mark 4: author review (Claude)

Verses reviewed: 39 of 41. 4:8 and 4:20 were kept unchanged from the earlier
review.

Check: `fromtext` → `{"versesOk": 41, "problems": 0}`.

49 publisher rows in 26 verses were changed because they were wrong or
over-claimed. Another 44 rows were only joined with a TODO token (article +
participle, idioms) or reshaped because a neighbouring correction moved a word
to them.

## Publisher rows corrected

- 4:1: Καί = "Once" was wrong → πάλιν = Once again, καί `s`. ἤρξατο = "Jesus
  began" → began, `t Jesus`. καθῆσθαι = "and sat" → sat, `t and` (after the
  participle ἐμβάντα). θαλάσσῃ = "it" was wrong: "it" is the boat, so
  `t it` and τῇ θαλάσσῃ `s`.
- 4:3: σπεῖραι = "to sow his seed" → to sow, `t his seed`.
- 4:5: εἶχεν = "it did not have" → οὐκ = not, εἶχεν = it did + have. μή =
  "was shallow" → τὸ μὴ ἔχειν βάθος = was shallow (as in Matthew 13:5).
- 4:6: ἐκαυματίσθη = "the seedlings were scorched" → were scorched,
  `t the seedlings`.
- 4:9, 4:13, 4:21, 4:26, 4:33, 4:39: "Jesus" was folded into the verb → `t Jesus`
  (the Greek has only a verb ending or participle). In 4:21 and 4:26 καί now
  carries "also" (publisher: "Jesus also said" on ἔλεγεν).
- 4:10: Καί = "As soon as" was wrong → ὅτε = As soon as, καί `s`. ἐγένετο =
  "Jesus was" → was. σύν = "and", τοῖς = "with the" → σύν = with, τοῖς = the,
  `t and`.
- 4:13: οἴδατε = "Do you not understand" → Οὐκ = not, οἴδατε = Do you +
  understand.
- 4:15: ἀκούσωσιν = "they hear it" → they hear, `t it`.
- 4:16: εὐθύς = "and at once" → at once, `t and` (BSB recasts the ὅταν clause).
- 4:17: ἔχουσιν = "they themselves have" → they + have; ἐν ἑαυτοῖς =
  themselves. εἶτα = "When" was wrong → εἶτα `s`, γενομένης = When + comes
  (genitive absolute). σκανδαλίζονται = "they quickly fall away" → εὐθύς =
  quickly, verb = they + fall away.
- 4:18: καί = "Others" was wrong → ἄλλοι = Others, καί `s`.
- 4:19: αἰῶνος = "of this life" → τοῦ = of, αἰῶνος = life, `t this` (N1904 and
  the publisher's Greek have no τούτου).
- 4:21: ἔρχεται = "Does anyone bring in" → Μήτι = Does, ἔρχεται = bring in,
  `t anyone`. τεθῇ = "he set it" → set it, `t he`.
- 4:22: μή = "will not be" and ἔλθῃ = "will not be brought" over-claimed →
  ἐὰν μή = not (first), ἀλλ’ = not (second, "except" after οὐδέ); the verbs
  carry will + be disclosed / will + be brought.
- 4:24: προστεθήσεται = "even more will be added" → more will be added,
  `t even`.
- 4:25: αὐτῷ = "more" was wrong → αὐτῷ `s` (expressed by "whoever" as the
  passive subject), `t more` (as in Matthew 13:12). ἔχει = "does not have" →
  οὐκ = not, ἔχει = does + have.
- 4:26: βάλῃ = "who scatters" → scatters, `t who`.
- 4:27: αὐτός = "though he" → he, `t though`.
- 4:31: ὡς = "It is like" → like, `t It is`. κόκκῳ = "a mustard seed" → a +
  seed; σινάπεως = mustard.
- 4:33: πολλαῖς = "With many such" → many; τοιαύταις = such; παραβολαῖς = With
  + parables (dative).
- 4:34: χωρίς = "without using" → without, `t using`. ἐλάλει = "He did not tell
  them anything" → οὐκ = not, ἐλάλει = He did + tell, αὐτοῖς = them,
  `t anything`. τοῖς = "to His" → to; ἰδίοις = His own.
- 4:35: Καί = "When" was wrong → καί `s`; γενομένης = When + came; ὀψίας =
  evening.
- 4:36: καί = "After" was wrong → καί `s`, ἀφέντες = After + they had
  dismissed. παραλαμβάνουσιν = "they took Jesus with them" → they took + with
  them; αὐτόν = Jesus.
- 4:38: μέλει = "don’t You care" → οὐ = don’t, μέλει = care, σοι = You.
- 4:39: ἐπετίμησεν = "and rebuked" → rebuked, `t and` (after διεγερθείς).
- 4:40: δειλοί = "so afraid" → afraid; ἔχετε = "Do you still have no" → Do you
  + have, οὐκ = no, `t still` (see below).

## Notable decisions

- Joint units from the TODO list: εἰς … ἐμβάντα = got into (4:1); κατὰ μόνας =
  alone (4:10); τοῖς ἔξω = on the outside, τὰ πάντα = everything (4:11);
  βλέποντες βλέπωσιν / ἀκούοντες ἀκούωσιν = may be ever seeing / ever hearing,
  μή ποτε = otherwise, ἀφεθῇ αὐτοῖς = be forgiven (4:12); ὅταν + εὐθύς = As
  soon as (4:15, 4:29); οὐ … τι = nothing (4:22); Οὕτως … ὡς = like (4:26);
  ἐν τῷ στάχυϊ = within (4:28); κατ’ ἰδίαν = privately (4:34); λαῖλαψ ἀνέμου =
  windstorm, τὸ πλοῖον = it (4:37); ἐφοβήθησαν φόβον μέγαν = Overwhelmed with
  fear, πρὸς ἀλλήλους = one another (4:41).
- Article + participle joined: ὁ σπείρων = A farmer / The farmer (4:3, 4:14);
  τὸν ἐσπαρμένον = that was sown (4:15); οἱ … σπειρόμενοι = the seeds sown
  (4:16, 4:18); εἰσιν οἱ … ἀκούσαντες = hear (4:18, following the kept 4:20).
- 4:15 and 4:18 keep εἰσιν = "are like", consistent with the kept 4:20; in
  4:16 ὁμοίως = like.
- Spelling forms, not different readings, linked with a note: συνπνίγουσιν =
  choke (4:19), εἶτεν = then and σῖτος = grain (4:28), κατασκηνοῖν = nest
  (4:32).
- 4:40: the publisher's Greek lacks οὕτως and reads οὔπω for πῶς οὐκ. οὕτως =
  so is linked (it is the N1904 word for BSB's "so"); οὐκ = no; `t still` and
  πῶς `s` name the οὔπω reading.
- Pronouns rendered by their referent kept: αὐτό = the seedlings (4:7),
  αὐτοῖς = His disciples (4:35), αὐτόν = Jesus (4:36), αὐτός = Jesus (4:38).
- Kept on purpose: καί = But / Soon / while (4:6, 4:37, 4:1); ἀλλά = and
  (4:17); πρόσκαιροι = for only a season (4:17); πλήρης = that ripens (4:28);
  Πῶς = To what (4:30); ᾧ = the (4:24); ἦσαν = crowded (4:1).

## Doubts for the peer

- 4:40: linking οὕτως = so although BSB's own Greek lacks it. The
  alternative is `s` οὕτως with a reading reason and `t so`.
- 4:1: ἐν = in is linked while τῇ θαλάσσῃ is `s` and "it" (the boat) is `t`.
  One could instead link ἐν τῇ θαλάσσῃ = in it as a phrase-level rendering.
- 4:10: σύν = with, `t and`. The publisher's view (σύν = and, since it joins
  the two groups) is also defensible.
- 4:16: ὅταν `s` and "and" `t`. Linking ὅταν = and is possible but does not
  render its meaning.
- 4:19: `t this` follows Matthew 13:22. Joining τοῦ αἰῶνος = of this life
  (the article marking the present age) is the alternative.
- 4:21: Μήτι = Does. It could be `s`, with "Does" then belonging to ἔρχεται.
- 4:22: ἐὰν μή and ἀλλ’ each carry "not" in BSB's "that will not be …"
  clauses.
- 4:35: ἐν ἐκείνῃ τῇ ἡμέρᾳ = that, as one group. The alternative is ἐκείνῃ =
  that and the other three tokens `s`.
- 4:31: the second ἐπὶ τῆς γῆς (publisher) carries "upon the earth"; the first,
  with ὅταν, is `s`. The reverse is also possible because "sown" comes from the
  first clause.
