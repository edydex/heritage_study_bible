## Publisher rows corrected

- 24:1: καί = "As" was wrong → ἐξελθών = As + left, καί explained.
  "and was walking away" → was walking away, `t and`. "came up to Him" →
  came up to; αὐτῷ = Him.
- 24:2: εἶπεν = "He replied" → ὁ = He, ἀποκριθεὶς εἶπεν = replied.
- 24:3: δέ = "While" was wrong → While + was sitting (genitive absolute).
  πότε = "when will" → when; ἔσται = will + happen. τί = "what will be" →
  what, `t will be`. συντελείας = "of the end" → of + end; the shared
  article τῆς = the.
- 24:5: "will deceive many" → will deceive; πολλούς = many.
- 24:6: "but see to it" → see to it, `t but`. "that you are not alarmed" on
  the verb → μή = not, verb = you are + alarmed, `t that`. γάρ = "These
  things" was wrong → γάρ explained, `t These things` (no subject in N1904).
- 24:8: "these are" → these, `t are` (verbless).
- 24:9: "over to" on εἰς → to; "over" joins the verb (deliver + over).
- 24:12: πληθυνθῆναι = "the multiplication" → τό = the.
- 24:15: ὁ = "let the" was wrong → ὁ ἀναγινώσκων = the reader, νοείτω =
  let + understand.
- 24:16: "then let" → then; φευγέτωσαν = let + flee. οἱ = "those who are"
  (lone article carrying "are") → those, `t who are`.
- 24:17, 24:18: ὁ = "Let no one" → ὁ = one, μή = no, imperative = Let +
  come down / let + return (ὀπίσω joined).
- 24:19: δέ = "How" was wrong → οὐαί = How + miserable. "days will be" →
  days, `t will be`.
- 24:20, 24:22, 24:29, 24:42, 24:43, 24:44, 24:50: the negative and the
  verb's auxiliary sat in one row ("will not occur", "had not been cut short",
  "will not give", "you do not know", οὐκ = "would not", "you do not expect",
  "he does not expect / anticipate") → οὐ / μή = not; the verb keeps the
  auxiliaries.
- 24:34, 24:35: "will not" / "will never" on οὐ → οὐ μή = not / never,
  verb = will + pass away.
- 24:21: "to be seen again" → to be seen, `t again`.
- 24:23: "here is" → here, `t is`. "There He is" → There, `t He is`.
  "do not" / "believe it" → μή = not, verb = do + believe, `t it`.
- 24:24: "that were possible" → possible, `t that were` (verbless).
- 24:25: "I have told you in advance" → ὑμῖν = you.
- 24:26: "do not" (×2) → not; verb = do + go out / do + believe, `t it`.
  "or, Here" → Here, `t or` (no ἤ in N1904). ἐν = "He is in" was wrong →
  in; the one ἐστίν = He is + He is.
- 24:32: "is near" → near, `t is` (verbless).
- 24:37, 24:39: "As it was" → As, `t it was in`. Lone articles αἱ / ἡ
  carried "in the" / "at the" → the, `t at`. "will it be" → will + be,
  `t it` (dummy subject; ἡ παρουσία is the subject).
- 24:38: "people were" → were, `t people` (verb ending only).
- 24:39: "swept them all away" → swept + away; ἅπαντας = them all.
- 24:41: "will be grinding" → grinding, `t will be` (verbless).
- 24:46: "Blessed is" → Blessed, `t is`. "him doing" → doing; ὃν … αὐτοῦ =
  whose + him.
- 24:47: "he will put him in charge" → αὐτόν = him.
- 24:48: "is wicked" / "and says" → wicked / says; `t is`, `t and`
  (attributive κακός recast as a clause).
- 24:51: "he will cut him to pieces" → αὐτόν = him. ἐκεῖ = "where there" →
  where; "there" joins ἔσται (there will be).

## Notable decisions

- Joint units: κατ’ ἰδίαν = privately; μή τις = that no one; οὐ μή = not /
  never (24:2, 21, 34, 35); ὃς οὐ = every one (24:2, double negative made
  positive); οἵα οὐ γέγονεν = unmatched; οὐκ … πᾶσα σάρξ = nobody; ἂν ἐσώθη =
  would be saved; ἐγρηγόρησεν ἄν, ἂν εἴασεν; ὅπου ἐάν = Wherever; ἕως ἄν =
  until; εἰ μή = but; ὅταν ἤδη = As soon as; διὰ τοῦτο = For this reason;
  κατὰ τόπους = in various places; τῶν πολλῶν = of most; ᾗ … ὥρᾳ = at an
  hour (24:44); ἄκρων αὐτῶν = the other; οὐκ ἔγνωσαν = they were oblivious;
  ἀποκριθεὶς … εἶπεν = replied / answered.
- Article + participle joined: ὁ ὑπομείνας, τὸ ῥηθέν = described, ὁ
  ἀναγινώσκων, ταῖς ἐν γαστρὶ ἐχούσαις = for pregnant, ταῖς θηλαζούσαις,
  τοῖς ὑπάρχουσιν = possessions, τῶν μεθυόντων = drunkards; articular
  infinitive τοῦ δοῦναι = to give.
- Two Greek words, one English: ὑμᾶς … ὑμᾶς = you (24:9) and ἀλλήλους …
  ἀλλήλους = one another (24:10), where English states the shared object once.
- 24:3: the one article τῆς governs παρουσίας and συντελείας, so it is
  linked to "the" before "end".
- Textual differences between N1904 and BSB:
  - 24:2: BSB renders Οὐ βλέπετε without the negative (`s`).
  - 24:6: N1904 δεῖ γὰρ γενέσθαι has no subject → `t These things`.
  - 24:26: N1904 has no conjunction before the second Ἰδού → `t or`.
  - 24:38: ἐκείναις is not rendered; some manuscripts omit it (`s`).
- Supplied English (`t`): copulas and verbs in verbless clauses (24:3, 8, 19,
  23, 24, 32, 41, 46, 48), "it" objects of believe (24:23, 26), "who are"
  (24:16), "people" (24:38), dummy "it" and "at" (24:37, 39), "again"
  (24:21), "but" and "that" (24:6), "and" (24:1, 24:48).
- Kept from the publisher on purpose: δύο = Two men / Two women; λίθος = one
  stone; ἄκρων = one end; φυλακῇ = watch of the night; ἐπί = right at
  (24:33); τήν = this lesson (24:32, article pointing ahead); αὐτοῖς = the
  others (24:45); ἰδού = There (24:26); γένηται = to be seen (24:21).

## Doubts for the peer

- 24:1: "As" is linked with the participle ἐξελθών (As + left), and the καί
  before προσῆλθον is `s`. One could instead make "As" `t` or link it to that
  καί, since English subordinates both Greek verbs of the first clause.
- 24:17, 24:18: μή = no and ὁ = one are linked separately ("no one"). The
  alternative is one joint group ὁ … μή = no one.
- 24:37, 24:39: "it" and "at" are `t`, because the Greek subject ἡ παρουσία
  is recast as "at the coming". Please check that this is not too strict.
- 24:21 "again", 24:33 "right at", 24:2 "one stone", 24:43 "of the night":
  I made only "again" `t`; the others stay as the publisher linked them.
- 24:31: "trumpet call" stays on σάλπιγγος; "call" might reflect the reading
  σάλπιγγος φωνῆς μεγάλης, which N1904 lacks.
- 24:46: ὃν … αὐτοῦ = whose + him is joint; the alternative is ὃν = him and
  αὐτοῦ = whose.
