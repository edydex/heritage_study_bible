Readings: EVIDENCE shows a difference from N1904 only in 3:6 and 3:9.
- 3:6: the verb "kills" is probably spelled ἀποκτέννει in BSB's Greek
  (N1904 ἀποκτείνει). Same verb, so it is linked with a note.
- 3:9: BSB's Greek probably has τῇ διακονίᾳ (dative) where N1904 has ἡ
  διακονία. The English "the#0" still renders the article, so ἡ = "the#0"
  with a note. No other reading is claimed.

## Notable decisions

- Key terms linked word by word: ἐπιστολή = "letter(s)" (3:1-3), διαθήκη =
  "covenant" (3:6, 3:14), γράμμα = "letter(s)" (3:6, 3:7), διακονία =
  "ministry" (3:7-9), δόξα = "glory"/"glorious" (3:7-11, 3:18), κάλυμμα =
  "veil" (3:13-16), ἐλευθερία = "freedom" (3:17), μεταμορφούμεθα = "are
  being transformed" (3:18). No interpretive notes.
- 3:1 μή is the question marker (`s`); ἤ = "Or".
- 3:3 φανερούμενοι = "is clear" (passive participle "being shown"); only
  "It" is `t`.
- 3:3 διακονηθεῖσα keeps "the#0 result of + ministry"; the agent ὑφ’ ἡμῶν
  = "our".
- 3:8 πῶς `s` (BSB's "will not … ?" has no "how"); ἐν δόξῃ = "glorious".
- 3:11 τὸ μένον = "that which endures"; ἐν δόξῃ = "the glory of".
- 3:15 ἀλλ’ keeps the publisher's "And even" (connective rendered with a
  different connective).
- 3:16 ἐπιστρέψῃ keeps "anyone turns" (person on the finite verb).
- 3:17 both clauses verbless where BSB has "is#1" and "there is": `t`.
- 3:18 ἀπὸ δόξης εἰς δόξαν = "with#1 intensifying glory" (one group, as
  Romans 1:17).

## Doubts for the peer

- 3:18 τὴν αὐτήν means "the same"; BSB has "His image". I made it `s` +
  "His" `t` (different meaning). The publisher linked αὐτήν = "His";
  linking τὴν αὐτήν = "His" with a note is the alternative.
- 3:10 five tokens ἐν τούτῳ τῷ μέρει εἵνεκεν ("in this respect, because
  of") joined as "in comparison to". Alternatives: ἐν τούτῳ τῷ μέρει = "in
  comparison" with εἵνεκεν = "to", or εἵνεκεν `s`.
- 3:5 ὡς `s` with "that#1" `t`; ὡς = "that#1" with a note is the
  alternative.
- 3:15 "even" stays on ἀλλ’ ("And even"); `t` for "even" as an added adverb
  is the stricter option.
- 3:9 περισσεύει … δόξῃ joined as "glorious#1 + is"; περισσεύει = "is"
  alone with δόξῃ = "glorious#1" is the alternative. 3:12 χρώμεθα παρρησίᾳ
  joined likewise.
- 3:3 "is" kept on φανερούμενοι ("is clear"); `t` for "is" as a supplied
  copula is the alternative.
