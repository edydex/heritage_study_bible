Importing a Bible for your church

Heritage imports plain-text Bible editions from authorized sources. The complete imported text stays in your church’s private database. Selected passages are copied into service documents with the translation ID, attribution and a content checksum, so SyncShow can present them offline.

Getting the Legacy Standard Bible

The LSB publisher asks software providers to contact info@316publishing.com for an agreement. Ask Three Sixteen Publishing for permission to use LSB in Heritage Community and SyncShow, including local storage, church projection, offline service packages and any intended livestream use, and for an authorized structured text file.

A retail, general-purpose LSB JSON download has not been verified. A module bought for another application is not an established import source for Heritage. The upload feature does not grant a license or unlock proprietary modules.

Sources: LSB publisher FAQ · LSB quotation permissions · ProPresenter Bible installation. Checked September 21, 2026.

Try the upload

  1. Download the BSB public-domain sample (Romans 1:1–3).
  2. In Bible translations, choose that JSON file and review its verses.
  3. Enter “CC0 / public domain” as the permission reference and confirm its use.
  4. Install the edition. In Prepare a sermon or Plan a service, choose Scripture, select BSB-DEMO for the English screen, enter “Rom 1 1-3”, and add the passage.

The sample is intentionally only three verses. Asking for verse 4 produces a missing-verse message.

Version 1 file format

UTF-8 JSON, at most 24 MiB. The sample is a complete working file. Required top-level fields: schemaVersion: 1, kind: "heritage-bible-translation", translation, books.

  • translation: id, name, language, edition, attribution, sourceUrl, license. Use a unique uppercase ID and a language code such as en, ru or uk. Attribution must be the required projection credit and fit within 500 characters.
  • Each book: canonical id and chapters. Each chapter: number and verses. Each verse: numeric number and plain text. No markup or footnote conversion is performed.
  • Canonical IDs match the planner catalog (Gen, Exod, 1Chr, Ps, Matt, John, Rom, etc.). Version 1 supports conventional 66-book chapter numbering. Other canons and alternative chapter numbering need an explicit adapter.
  • Partial editions are labelled by their supplied counts. Duplicate identities and unsupported fields are rejected. Verse strings are retained exactly; the importer never fills omissions or translates words.
  • Built-in IDs cannot be replaced. A changed edition needs a new ID. Existing slides keep their originally selected text.

Direct OSIS, USFM, e-Sword, ProPresenter and encrypted-module imports are not implemented in version 1. Publisher-approved structured exports can be converted to this JSON shape without changing their text.
